# Scenario Manager Frontend

React, TypeScript, Three.js, and Vite client for editing and running scenarios.

## Setup

```bash
corepack enable
yarn install --frozen-lockfile
yarn dev
```

The development server is available at `http://localhost:5173` and expects the
backend URL from `.env.development`.

## Commands

```bash
yarn build
yarn test
yarn test:e2e
yarn lint
yarn analyze
```
